# ptcg-az
Tool to help make a Pokemon TCG - AZ League

## Legends AZ (web)

Base do app em **HTML/CSS/JS puro**:

- `index.html` (Jogadores - padrão)
- `torneios.html`
- `styles.css`
- `shared.js` (tema + navegação)
- `torneios.js`
- `jogadores.js`

Para rodar, basta abrir o `index.html` no navegador (ou usar qualquer servidor estático).
